From a problem to a reusable fix

  1. Choose New fix. Give the problem a memorable title.
  2. Record what you tried and whether it worked.
  3. Add the solution and optional numbered steps. Mark it solved.
  4. Click Save fix. Search for it whenever the problem returns.

Your notebook lives in this browser

Saved fixes use this browser’s local storage. They are not written into the app’s HTML file. Use the same browser, profile, and file location to return to them. Private browsing, clearing site data, moving or renaming the HTML file, or changing browsers may make those notes unavailable.

Export a backup regularly. Restore the JSON file to move your notes to another browser or computer. Screenshots are included. The app makes no network requests and has no account, analytics, or cloud sync. Files and backups are not password encrypted.

Follow, print, or share a solution

Use Follow steps to tick through a fix. Checkmarks reset when you leave that fix and don’t change your notes. Print opens the browser’s print dialog, where available you can select Save as PDF. Save card downloads a standalone HTML instruction card with its images. That card is a readable copy, not an editable notebook backup.

Small shortcuts, useful limits

Ctrl / ⌘ + K searches your notebook. Ctrl / ⌘ + S saves an open editor. Esc closes a dialog, with a prompt if you have unsaved changes.

Up to 500 fixes, 30 attempts and 30 steps per fix, 6 images per fix, and a 50 MB notebook. Images up to 15 MB are resized to at most 1,600 px. A backup merge keeps both versions when the same fix has changed; review duplicates afterward.

Using the app

Extract the ZIP, then open index.html in a modern desktop browser with JavaScript enabled. Chrome, Edge, Firefox, and Safari are intended targets; storage behavior for local HTML files varies. A warning appears if browser storage cannot be opened. In that mode, export your work before closing the tab.

Example fixes are fictional demonstrations, not device-specific instructions. Your own notes stay separate unless you choose to copy an example.
